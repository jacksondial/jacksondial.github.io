Privacy Policy – Job Application Tracker

Last updated: October 14, 2026

Job Application Tracker is a personal automation used only by its owner.

Data accessed

The app reads the owner's Gmail messages to identify job application emails, applies labels to those messages, and writes application details to the owner's Google Sheet.

How data is used

Email content is sent to Anthropic's API solely to classify messages and extract application details. Data is not sold, shared for advertising, or used for any other purpose.

Google user data

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from Google Account permissions.
